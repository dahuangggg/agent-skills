# Knowledge Mastery Track

Each lesson teaches exactly one small objective and produces one tangible win. Split lessons when they require multiple new mental models or independent skills.

## Lesson shape

1. Objective and observable success criteria
2. Required foundation, refreshed immediately before use
3. One core concept or skill
4. Concrete example from the repository
5. Diagram when relationships are non-trivial
6. Guided practice
7. Retrieval question or interactive quiz with immediate feedback
8. Explanation of wrong paths and common misconceptions
9. Delayed-review prompt
10. Repository evidence and one best primary source
11. Links to relevant reference pages and adjacent lessons

Optimize for learning the concept, not for covering every detail of the associated module. Prefer several short dependent lessons to a survey chapter.
